# Caristini: VW group customisation ("tweak") catalogue

Research note, 11 Nov 2026. Scope: VW, Audi, SEAT, Skoda and Cupra coding tweaks with exact coding locations, from public sources only. Owner's cars first (Audi A6 C7 2012, SEAT Leon II 1P1 Cupra 2007), then platforms (MQB, MQB evo, MLB evo, PQ25/PQ26, PQ46). Companion to `coding-sources.md` (write sequence, logins, service reset), `vag-sources.md` (MLB discovery and transport) and `leon-sources.md` (PQ35 KWP2000 detail). Rows here are facts as stated by each source; nothing is copied wholesale from a label file or a tool database.

## Conventions

- Columns: `id | title | module | type | byte | bits | value_on | value_off | login | confidence | sources | notes`.
- `type`: long coding, adaptation, short coding or basic setting.
- `byte`: VCDS Long Coding Helper byte, counted from 0 (byte 0 = first data byte after `62 06 00` on UDS). Bit n = `(byte >> n) & 1`, bit 0 = least significant. Adaptation rows hold `ch:` and the channel number (KWP) or name (UDS) in `byte`, and the value in `value_on`. Short coding rows describe the digit position in `byte` and the amount to add in `value_on`. `param:` marks a text-coded parameter with no byte given.
- Multi-bit fields are noted as such; never write a field from a single "bit" instruction.
- `login`: the security access or login code as the source states it. Blank or "none" = no code stated (not proof that none is needed).
- `sources`: full URLs separated by " ; ".
- Confidence: **High** = 2 or more independent sources agree, a Ross-Tech wiki page, or a source plus an owner report that it worked; **Medium** = 1 detailed source, or a label/real-coding match; **Low** = vague, search-result text only, sibling car only, or sources disagree. Copies of the same list count once (see the A6 C7 note).
- Every byte map depends on the module part number and software. Before any write: read the coding, show the current bit, check the coding length against the source car, save a backup.

## Risks that apply across tables

- Seat belt and airbag: seat belt reminder changes alter a safety warning; values are often multi-bit fields with an unpublished "inactive" value. Airbag (15) coding is not documented publicly. Do not offer.
- Lighting in the UK: DRL must stay on cars type-approved from Feb 2011; high beam or fog lamps as DRL, amber front position lamps (US side markers) and rear fog behaviour changes can break the Road Vehicles Lighting Regulations 1989 or fail an MOT; Highway Code rule 236 limits rear fog use. Headlamp washers are required with xenon or LED headlamps over 2000 lm (ECE R48). Flashing brake lamps are only lawful within the ECE R48 emergency stop signal rules. These notes were not checked against the regulation text.
- Brake and steering modules (03, 44, 53): wrong coding can disable ABS/ESP or EPB safeguards. Do not offer writes.
- MMI video in motion and input-while-driving unlocks: distraction risk; video visible to the driver while moving is unlawful in the UK.
- Writes are logged in the module with the workshop code and date (`coding-sources.md` A6).

## What this adds to the existing notes

- A6 C7 comfort windows/sunroof by remote: 46 long coding byte 2 bit 2 "Comfort operation: Remote control active" (High). `coding-sources.md` A3 had the byte as Unconfirmed.
- A6 C7 mirror fold on lock: 42 and 52 byte 4 bit 6 (Medium), 46 byte 7 bit 7 (Low); engine keeps running on door open: 46 byte 15 bit 3 (Medium). The 2012 A7 real codings on vagcode.info fit these bits.
- A6 C7 seat belt warning: the forum "byte 0 bit 4 inactive" conflicts with the labelled real coding (field value 4 = escalated reminder active). Kept Low; still do not offer.
- A6 C7: 13 more adaptation tweaks with owner results (single gear display, ACC distance menu, lane assist timing menu, heated seat timer, DRL dim level, double chirp, green menu).
- MQB oil temperature: 17 byte 10 bit 1 (High, three sources). `vag-sources.md` section 3 had bit 0 or 1 as ambiguous.
- Leon 1P needle sweep: not available on pre-facelift clusters (several Leon owners); facelift clusters 1P0 920 952/954 use 17 adaptation "Staging" (Medium).
- Leon 1P comfort turn signals: label dumps give 09 byte 2 bit 1; the DanGB "byte 2 bit 8" in `coding-sources.md` B is wrong as written.
- Leon 1P 09 BCM: two coding layouts (23-byte and 30-byte) and a facelift BCM (1K0 937 087) whose bit names are not public. Read the BCM part number before using any 09 row.
- MQB evo: SFD replaces login codes; old codes such as 31347 are reported not to work on Golf 8 BCMs.

## Audi A6 C7 (4G) 2012, MLB, VIN WAUZZZ4GXCN000000

Applies to A6/A7 4G and, where marked "D4", to the A8 D4 (same MLB BCM1 4H0 907 063 and BCM2 4H0 907 064 families, Ross-Tech wiki MLB BCM pages). D4 rows are sibling evidence only.

Read this first:

- Source independence. The Google Doc "Audi C7 VCDS Tweaks" (GD), the Ross-Tech forum list by Devilz (RT8599, 23 Dec 2016), the untanux.lt blog (UT, 26 Sep 2019) and the audisg list by CRViper (SG, Jul 2016) are near copies of one list (same order, same "61378 probably"). They count as one source. What makes a row High is an owner reporting that the item worked (Metzga, jlr83, Ricckky, dp1199/DB22 on AudiWorld; "activated" status notes by Devilz or untanux), the Jack88 A8 D4 list, or a labelled real coding on vagcode.info.
- Real-coding cross-check (my decode, Medium): the 2012 A7 log on vagcode.info shows 46 coding byte 2 = 0E (bit 2 set), byte 7 = 81 (bit 7 set), byte 8 = 83 (bits 0 and 1 set); 42 and 52 byte 4 = 5E (bits 2 and 6 set); 09 byte 16 = CF (bit 6 set). These agree with the bit positions below for comfort remote, mirror fold, adaptive brake lights, mirror dip and footwell lighting on a car that likely has those features.
- Transport. 17 is UDS (714/77E). On the C7, 09, 46, 42 and 52 are KWP2000 on TP2.0 and their write sequence is not public (`vag-sources.md` section 2). "App now?" in notes: Yes only for 17 items.
- MMI. 5F rows apply to MMI 3G/3G+ (2012 car). C7.5 (MY2016+) MIB units use different names; several 5F rows were reported to fail on C7.5.
- Adaptation channel numbers below are VCDS numbers for KWP modules; on UDS modules the channel is a named DID, not public.

## SEAT Leon II 1P1 Cupra 2007 (PQ35)

Conventions: bit n = (byte >> n) & 1, bit 0 least significant (checked against vagcode.info label dumps, where byte 0 = A3 hex shows bits 0, 1, 5, 7 set). Long coding bits: value_on 1, value_off 0. Short coding: value_on is the amount added to the stated digit(s). Adaptation: byte = ch:NNN. BCM families referred to in notes: "BCM-23" = 23-byte coding, label 3C0-937-049-23-H (seen on 1K0 937 049 N, 3C0 937 049 E, 3C0 937 049 AE); "BCM-30" = 30-byte coding, label 3C0-937-049-30-H (seen on 3C8 937 049 E/AC); "BCM-H+" = BCM PQ35 H+ 1K0 937 087 x, label 1K0-937-08x-09.clb (2008+, used on facelift cars). Compiled 11 Nov 2026 from public web pages fetched on that date. Facts only, as stated by each source. Bit numbering: bit n = (byte >> n) & 1, bit 0 = least significant, which matches the VCDS Long Coding Helper. Channel numbers in brackets, for example "(15)", are VCDS list positions quoted by the source; they vary by module software and are not stable identifiers. Always save an Auto-Scan and an 09 adaptation channel map before changing anything (Ross-Tech wiki, Golf VII page).

MQB and MQB evo general notes:
- MQB 09 (BCM) adaptation login: 31347 in most sources. One Leon MY18 poster says the login step was not needed on the facelift. Ross-Tech forum thread 512 uses 20103 for 09 comfort-window channels.
- From about summer 2016 / MY2017-MY2018 many MQB BCMs have an all-zero long coding and functions moved to adaptation (Ross-Tech forum thread 10616). Channel names also changed for MY2018 (for example "Access Control 2" became "ZV Komfort").
- Some newer cars need the bonnet open for writes (diagnostic firewall, Ross-Tech wiki).
- MQB evo (Golf 8, Octavia 4, Leon 4, A3 8Y, Formentor): SFD replaces login codes; coding, adaptation, basic settings and output tests may need an SFD unlock first, which times out and relocks. Neither VCDS nor ODIS can disable SFD or SFD2 permanently (Ross-Tech wiki SFD page). A Golf 8 owner reports 31347 does not work on the Mk8 BCM and an OBDeleven moderator states "SA and SA2 are deprecated. Use SFD instead."

Conventions: bytes count from 0 as shown in the VCDS Long Coding Helper (LCH) and OBDeleven long coding; bit n = (byte >> n) & 1, bit 0 = least significant. Where a source gives a parameter name (text long coding) and no byte, the byte column holds "param:" and the name. For long coding rows value_on / value_off are the bit state that switches the feature on / off (some flags are inverted, see notes). For adaptations the byte column holds "ch:" and the channel. Every byte map depends on the control module part number and software; save the original coding before writing. Bit positions taken from vagcode.info are that site's decode of one logged car's coding (single source, verified where possible against the logged coding string).
